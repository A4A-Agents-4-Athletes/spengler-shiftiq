## Slide 4 (Proposal Slide 4 of 5): Technical Architecture & Zero-Latency Pipeline
*Jury Criterion #4: Technical Implementation*

- **Headline**: **Production-Ready Web SDK Built on 100% Authentic Wisehockey Data**
- **Left Column — End-to-End Data Pipeline & Frontend Architecture**:
  - **Automated Python Ingestion (`ingest_official_sample_pack.py`)**: Parses all 40 skaters (23 columns) from `aggregated_stats_sample.xlsx` and all 284 multi-skater event rows (116 columns) from `event_data_sample.xlsx`, cross-referencing shot velocities, pass speeds, and momentum swings into a compact JSON payload (`33 KB`).
  - **60fps Hardware-Accelerated SVG Rink Engine**: Maps Wisehockey rink coordinates (`-30..+30m X`, `-15..+15m Y`) to a `1000x500` vector ice sheet with zero external canvas bloat and sub-second load on stadium 4G/5G.
  - **Strictly Compliant Public Repo**: Raw confidential `.xlsx`/`.pdf` datasets are excluded via `.gitignore` per Challenge Rule 5.
- **Right Column — Mobile Ergonomics, Bilingual Parity & Embed SDK**:
  - **True Mobile-First Thumb Ergonomics (`390x844` iPhone Viewport)**: Fixed 6-tab bottom dock (`>= 44x44px` touch targets) and auto-collapsing `36px` match strip on deep tools.
  - **Full German (`DE`) & English (`EN`) Localization**: 1-tap language toggle translating every tactical insight, quiz prompt, and broadcast overlay.
  - **Zero-Dependency Web Component / Iframe Ready**: Drops directly into `spenglercup.ch` or the HCD Mobile App in `<10` lines of code.
- **Speaker Notes (5:45 – 7:00)**:
  > *"Under the hood, ShiftIQ is engineered for Christmas-week reliability in Davos. Our Python ingestion pipeline parses the 23-column aggregated player sheet and 116-column event telemetry stream into a 33-kilobyte web payload. That means when 6,200 fans in Eisstadion Davos or 500,000 SRF viewers scan a QR code simultaneously, the entire 60fps vector SVG app loads in under one second in mobile Safari or Chrome—with zero app store friction and instant German/English switching."*
